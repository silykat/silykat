# Code of conduct

silykat follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and respectful, assume good faith, and focus on what is best for the project and its users. Harassment, insults and personal attacks are not welcome, in issues, pull requests or anywhere else in the project.

To report unacceptable behavior, write to **contact@silykat.com**. Reports are handled confidentially.
